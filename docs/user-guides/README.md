# User Guides

Documents in this folder are written for clients and operations teams, using
plain language rather than technical implementation terms.

- [SEO Copilot Client User Guide (English)](seo-copilot-client-guide-en.md)
- Word deliverable: `SEO_Copilot_Client_User_Guide_EN.docx`.
- [Vietnamese client guide](seo-copilot-client-guide-vi.md) and
  `SEO_Copilot_Client_User_Guide_VI.docx` remain available as internal
  reference copies.

Each Word file is generated from its Markdown source of truth and checked for
structure/accessibility. When publishing from a machine with LibreOffice, run
visual render QA through the Documents skill.

Technical operating notes and feature handoff documentation are in
[Feature Notes](../feature-notes/README.md).
